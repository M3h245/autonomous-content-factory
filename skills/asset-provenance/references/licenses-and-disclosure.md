# Licenses and disclosure
| License | Allowed | Obligation |
|---|---|---|
| self-generated (SVG, procedural, Kokoro output, procedural music) | yes | none (Kokoro model Apache-2.0 credited) |
| OFL-1.1 fonts | yes | ship license with font; credit |
| CC0-1.0 | yes | none |
| Pexels License / Pixabay Content License | yes | credit recommended; no implying endorsement; check people/brands |
| CC-BY-4.0 | yes | attribution text required (blocking if missing) |
| commercial-licensed | yes | `license_ref` required (invoice/licence id) |
| SD checkpoint output | after human confirmation | record checkpoint license in RUN/licenses.json |
| unknown / "found online" | no | replace the asset |
Disclosure decision (policy as checked 2026-10-03, re-verify): YouTube label when visuals are realistic synthetic or music
is AI-generated; TikTok/Instagram label when visuals or voice are realistic synthetic (conservative); always add a
description line naming AI narration and visual method; never depict real people saying things they did not say.
Voice clones of real people require recorded consent (`consent: true`) or the package is blocked.
