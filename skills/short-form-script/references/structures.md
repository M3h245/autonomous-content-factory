# Structures and budgets
Word budgets (English ≈ 3 words/s incl. pauses): 20 s ≈ 55 · 30 s ≈ 85 · 45 s ≈ 125 · 60 s ≈ 165.
- explainer: hook → setup (what we see) → value (mechanism) → twist (the surprising part) → payoff → loop
- myth-bust: hook (the myth) → setup (why people believe it) → value (evidence) → payoff (the truth) → cta/loop
- listicle (3 items max in a short): hook → item 1 → item 2 → item 3 (best last) → payoff
- story: hook (moment) → setup (stakes) → twist → payoff (lesson tied to a fact)
- how-to: hook (result) → step 1–3 → payoff (what changes) · comparison: hook → A → B → verdict
- question: hook (question) → wrong answer → right answer → payoff · news: hook → what happened → why it matters → what next
Ear rules: one idea per sentence, ≤ 20 words, concrete nouns, numbers as spoken, no parentheses, no lists of 5+.
Loop ending: last line restates the hook's claim so the replay feels seamless.
